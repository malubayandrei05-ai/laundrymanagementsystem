START HERE: LaundriFlow
1) Import backend/database/schema.sql in phpMyAdmin.
2) Backend: cd backend, copy .env.example .env, npm install, npm run dev.
3) Frontend: new terminal, cd frontend, npm install, npm run dev.
4) Open Vite URL (usually localhost:5173).
5) Initial Admin setup can only be done once. Customers self-register. Admin creates staff/rider accounts.
See README.md for details.
